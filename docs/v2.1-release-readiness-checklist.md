## Release cut instructions (exact commands)

### 1) Sync and verify main
```bash
git checkout main
git pull --ff-only origin main
mvn test
cd frontend && npm run lint && npm run build && npm run test:e2e:smoke
cd ..
```

### 2) Backup before deploy
```bash
export OPENPULSE_DB_URL='postgresql://<user>:<password>@<host>:5432/openpulse'
pg_dump --format=custom --file=openpulse-predeploy-$(date +%F-%H%M%S).dump "$OPENPULSE_DB_URL"
```

### 3) Changelog + release commit (if pending)
```bash
git add CHANGELOG.md README.md OPERATIONS_RUNBOOK.md .github/release-template.md docs/v2.1-release-readiness-checklist.md
git commit -m "docs(release): close v2.1 readiness gate and FE v1 evidence"
```

### 4) Tag and push
```bash
export VERSION="v2.1.0"
git tag -a "$VERSION" -m "Open Pulse Checker $VERSION"
git push origin main
git push origin "$VERSION"
```

### 5) Deploy and verify
```bash
# Example compose path
docker compose -f docker-compose.prod.yml pull
docker compose -f docker-compose.prod.yml up -d
curl -fsS http://localhost:8080/actuator/health
curl -fsS http://localhost:8080/actuator/info
```

## Rollback validation steps (exact commands)
```bash
# identify last known good tag
git tag --sort=-creatordate | head -n 5

# deploy prior tag image/build artifact per platform policy
# then run DB restore if migration/data rollback is required
pg_restore --clean --if-exists --no-owner --dbname="$OPENPULSE_DB_URL" openpulse-predeploy-<timestamp>.dump

# smoke verify after rollback
curl -fsS http://localhost:8080/actuator/health
curl -fsS http://localhost:8080/api/v1/health
cd frontend && npm run test:e2e:smoke
```
